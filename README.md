# Pocket Plaza 🌳

A cute avatar social game for phone browsers (Android and iPhone), inspired by classic avatar-world games.

- Dress up your chibi avatar in the Style Studio
- Walk around the plaza, chat and send emotes
- Decorate your own room with furniture, wallpaper and floors
- Earn coins in three mini-games: Star Catch, Bubble Pop and Memory Match

## Play

Open `index.html` in any browser, or play the hosted version on GitHub Pages:
https://kalsoomsite.github.io/pocket-plaza/

On a phone, use the browser's **Add to Home Screen** option so it opens like an app.

## Note

This is a single-file game. Hosted on GitHub Pages, it runs in solo mode: progress is saved
in each player's browser, and the online plaza, live chat and room visiting are turned off,
because those need a realtime server.
